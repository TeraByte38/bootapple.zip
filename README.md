# bootapple.zip
Bad Apple, but its the Android bootanimation.zip.

Basically Bad Apple made into a .png image sequence and a .wav.

Resolution is the same at the nicovideo video when downloaded (512x384) and it doesnt scale. 

If the boot animation lags, the audio and video will get desynchronized.

Download: https://drive.google.com/file/d/1WjVBz_WGACKARbYvJDiEFcIuRcp6rVOj/view?usp=sharing

Uses the original video: https://www.nicovideo.jp/watch/sm8628149?via=thumb_watch&at=title&state=unplayed
